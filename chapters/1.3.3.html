1.3.3  
Functions as General Methods
一般的な方法としての 関数

We introduced compound functions in section 1.1.4 as a mechanism for abstracting patterns of numerical operations so as to make them independent of the particular numbers involved. With higher-order functions, such as the integral function of section 1.3.1, we began to see a more powerful kind of abstraction: functions used to express general methods of computation, independent of the particular functions involved. In this section we discuss two more elaborate examples—general methods for finding zeros and fixed points of functions—and show how these methods can be expressed directly as functions.
 1.1.4節で、特定の数値に依存しないように数値演算のパターンを抽象化するメカニズムとして、複合 関数 を導入しました。 1.3.1節の integral 関数 のような高階 関数 を使うことで、より強力な種類の抽象が見えてきました。特定の関数に依存しない、計算の一般的な方法を表現するために 関数 を使うのです。この節では、2つのより精巧な例——関数の零点と不動点を見つける一般的な方法——を議論し、これらの方法を直接 関数 として表現できることを示します。

Finding roots of equations by the half-interval method
二分法による方程式の根の探索

The half-interval method is a simple but powerful technique for finding roots of an equation $f(x)=0$, where $f$ is a continuous function. The idea is that, if we are given points $a$ and $b$ such that $f(a) < 0 < f(b)$, then $f$ must have at least one zero between $a$ and $b$. To locate a zero, let $x$ be the average of $a$ and $b$ and compute $f(x)$. If $f(x) > 0$, then $f$ must have a zero between $a$ and $x$. If $f(x) < 0$, then $f$ must have a zero between $x$ and $b$. Continuing in this way, we can identify smaller and smaller intervals on which $f$ must have a zero. When we reach a point where the interval is small enough, the process stops. Since the interval of uncertainty is reduced by half at each step of the process, the maximal number of steps required grows as $\Theta(\log( L/T))$, where $L$ is the length of the original interval and $T$ is the error tolerance (that is, the size of the interval we will consider small enough). Here is a function that implements this strategy:
二分法は、$f$ が連続関数であるような方程式 $f(x)=0$ の根を見つけるための、単純ですが強力なテクニックです。アイデアは、$f(a) < 0 < f(b)$ となる点 $a$ と $b$ が与えられれば、$f$ は $a$ と $b$ の間に少なくとも1つの零点を持つ、というものです。零点を見つけるには、$x$ を $a$ と $b$ の平均とし、$f(x)$ を計算します。$f(x) > 0$ なら、$f$ は $a$ と $x$ の間に零点を持ちます。$f(x) < 0$ なら、$f$ は $x$ と $b$ の間に零点を持ちます。この方法を続ければ、$f$ が零点を持つべきますます小さい区間を特定できます。区間が十分に小さくなった時点でプロセスは停止します。不確実性の区間がプロセスの各ステップで半分に減るため、必要な最大ステップ数は $\Theta(\log( L/T))$ のように増加します。ここで $L$ は元の区間の長さ、$T$ は許容誤差（つまり、十分に小さいと見なす区間のサイズ）です。この戦略を実装した 関数 は次の通りです： 
function search(f, neg_point, pos_point) {
    const midpoint = average(neg_point, pos_point);
    if (close_enough(neg_point, pos_point)) {
        return midpoint;
    } else {
        const test_value = f(midpoint);
        return positive(test_value)
               ? search(f, neg_point, midpoint)
               : negative(test_value)
               ? search(f, midpoint, pos_point)
               : midpoint;
    }
}

We assume that we are initially given the function $f$ together with points at which its values are negative and positive. We first compute the midpoint of the two given points. Next we check to see if the given interval is small enough, and if so we simply return the midpoint as our answer. Otherwise, we compute as a test value the value of $f$ at the midpoint. If the test value is positive, then we continue the process with a new interval running from the original negative point to the midpoint. If the test value is negative, we continue with the interval from the midpoint to the positive point. Finally, there is the possibility that the test value is 0, in which case the midpoint is itself the root we are searching for. To test whether the endpoints are close enough we can use a function similar to the one used in section 1.1.7 for computing square roots:
最初に関数 $f$ と、その値が負の点と正の点が与えられると仮定します。まず2つの与えられた点の中点を計算します。次に、与えられた区間が十分に小さいかどうかを確認し、そうであれば単に中点を答えとして返します。そうでなければ、中点での $f$ の値をテスト値として計算します。テスト値が正なら、元の負の点から中点までの新しい区間でプロセスを続けます。テスト値が負なら、中点から正の点までの区間で続けます。最後に、テスト値が 0 である可能性があり、その場合は中点自体が探している根です。 端点が十分に近いかどうかをテストするために、 1.1.7節で平方根を計算するのに使ったものと同様の 関数 を使えます：
[1] 
function close_enough(x, y) {
    return abs(x - y) < 0.001;
}

The function search is awkward to use directly, because we can accidentally give it points at which $f$'s values do not have the required sign, in which case we get a wrong answer. Instead we will use search via the following function, which checks to see which of the endpoints has a negative function value and which has a positive value, and calls the search function accordingly. If the function has the same sign on the two given points, the half-interval method cannot be used, in which case the function signals an error.
関数 search を直接使うのは厄介です。なぜなら、$f$ の値が必要な符号を持たない点をうっかり与えてしまう可能性があり、その場合は誤った答えが得られるからです。代わりに、次の 関数 を通じて search を使います。この 関数 は、端点のどちらが負の関数値を持ち、どちらが正の値を持つかを確認し、それに応じて search 関数 を呼び出します。2つの与えられた点で関数が同じ符号を持つ場合、二分法は使えないため、 関数 はエラーを通知します。
[2] 
function half_interval_method(f, a, b) {
    const a_value = f(a);
    const b_value = f(b);
    return negative(a_value) && positive(b_value)
           ? search(f, a, b)
           : negative(b_value) && positive(a_value)
           ? search(f, b, a)
           : error("values are not of opposite sign");
}

The following example uses the
次の例は
half-interval method to approximate $\pi$ as the root between 2 and 4 of $\sin\, x = 0$:
二分法を使って、$\sin\, x = 0$ の2と4の間の根として $\pi$ を近似します：
half_interval_method(math_sin, 2, 4);

3.14111328125

Here is another example, using the half-interval method to search for a root of the equation $x^3 - 2x - 3 = 0$ between 1 and 2:
もう一つの例として、二分法を使って方程式 $x^3 - 2x - 3 = 0$ の1と2の間の根を探索します：
half_interval_method(x => x * x * x - 2 * x - 3, 1, 2);

Finding fixed points of functions
関数の不動点の探索

A number $x$ is called a fixed point of a function $f$ if $x$ satisfies the equation $f(x)=x$. For some functions $f$ we can locate a fixed point by beginning with an initial guess and applying $f$ repeatedly,
数 $x$ が方程式 $f(x)=x$ を満たすとき、$x$ は関数 $f$ の 不動点と呼ばれます。関数 $f$ によっては、初期推測から始めて $f$ を繰り返し適用することで不動点を見つけることができます。
\[ \begin{array}{l} f(x), \ f(f(x)), \ f(f(f(x))), \ \ldots \end{array} \]
until the value does not change very much. Using this idea, we can devise a function fixed_point that takes as inputs a function and an initial guess and produces an approximation to a fixed point of the function. We apply the function repeatedly until we find two successive values whose difference is less than some prescribed tolerance:
値があまり変化しなくなるまで続けます。このアイデアを使って、関数と初期推測を入力として受け取り、その関数の不動点の近似を生成する 関数 fixed_point を考案できます。連続する2つの値の差がある規定の許容値より小さくなるまで、関数を繰り返し適用します： 
const tolerance = 0.00001;
function fixed_point(f, first_guess) {
    function close_enough(x, y) {
        return abs(x - y) < tolerance;
    }
    function try_with(guess) {
        const next = f(guess);
        return close_enough(guess, next)
               ? next
               : try_with(next);
    }
    return try_with(first_guess);
}
For example, we can use this method to approximate the fixed point of the cosine function, starting with 1 as an initial approximation:
例えば、この方法を使って、初期近似値を1として 余弦関数の不動点を近似できます：
[3] 
fixed_point(math_cos, 1);

0.7390822985224023
Similarly, we can find a solution to the equation $y=\sin y + \cos y$:
同様に、方程式 $y=\sin y + \cos y$ の解を見つけることもできます：
fixed_point(y => math_sin(y) + math_cos(y), 1);

1.2587315962971173

The fixed-point process is reminiscent of the process we used for finding square roots in section 1.1.7. Both are based on the idea of repeatedly improving a guess until the result satisfies some criterion. In fact, we can readily formulate the square-root computation as a fixed-point search. Computing the square root of some number $x$ requires finding a $y$ such that $y^2 = x$. Putting this equation into the equivalent form $y = x/y$, we recognize that we are looking for a fixed point of the function $y \mapsto x/y$, and we can therefore try to compute square roots as
不動点プロセスは、 1.1.7節で平方根を求めるのに使ったプロセスを思い起こさせます。どちらも、結果がある基準を満たすまで推測を繰り返し改善するという考えに基づいています。実際、 平方根の計算を不動点探索として容易に定式化できます。ある数 $x$ の平方根を計算するには、$y^2 = x$ となる $y$ を見つける必要があります。この方程式を等価な形 $y = x/y$ にすると、関数 $y \mapsto x/y$ の不動点を探していることがわかります。そこで、平方根を次のように計算してみることができます。
[4] 
function sqrt(x) {
    return fixed_point(y => x / y, 1);
}
Unfortunately, this fixed-point search does not converge. Consider an initial guess $y_1$. The next guess is $y_2 = x/y_1$ and the next guess is $y_3 = x/y_2 = x/(x/y_1) = y_1$. This results in an infinite loop in which the two guesses $y_1$ and $y_2$ repeat over and over, oscillating about the answer.
残念ながら、この不動点探索は収束しません。初期推測 $y_1$ を考えてみましょう。次の推測は $y_2 = x/y_1$ で、その次の推測は $y_3 = x/y_2 = x/(x/y_1) = y_1$ です。これは、2つの推測 $y_1$ と $y_2$ が答えの周りを振動しながら繰り返される無限ループになります。

One way to control such oscillations is to prevent the guesses from changing so much. Since the answer is always between our guess $y$ and $x/y$, we can make a new guess that is not as far from $y$ as $x/y$ by averaging $y$ with $x/y$, so that the next guess after $y$ is $\frac{1}{2}(y+x/y)$ instead of $x/y$. The process of making such a sequence of guesses is simply the process of looking for a fixed point of $y \mapsto \frac{1}{2}(y+x/y)$:
このような振動を制御する一つの方法は、推測があまり大きく変化しないようにすることです。答えは常に推測 $y$ と $x/y$ の間にあるので、$y$ と $x/y$ の平均を取ることで、$x/y$ ほど $y$ から離れていない新しい推測を作れます。つまり、$y$ の次の推測は $x/y$ ではなく $\frac{1}{2}(y+x/y)$ です。このような推測の列を作るプロセスは、$y \mapsto \frac{1}{2}(y+x/y)$ の不動点を探すプロセスにほかなりません： 
function sqrt(x) {
    return fixed_point(y => average(y, x / y), 1);
}
(Note that $y=\frac{1}{2}(y+x/y)$ is a simple transformation of the equation $y=x/y$; to derive it, add $y$ to both sides of the equation and divide by 2.)
（$y=\frac{1}{2}(y+x/y)$ は方程式 $y=x/y$ の単純な変換であることに注意してください。導出するには、方程式の両辺に $y$ を加えて 2 で割ります。）

With this modification, the square-root function works. In fact, if we unravel the definitions, we can see that the sequence of approximations to the square root generated here is precisely the same as the one generated by our original square-root function of section 1.1.7. This approach of averaging successive approximations to a solution, a technique we call average damping, often aids the convergence of fixed-point searches.
この修正により、平方根 関数 は正しく動作します。実際、定義を展開してみると、ここで生成される平方根への近似の列は、 1.1.7節の元の平方根 関数 が生成するものとまったく同じであることがわかります。解への逐次近似を平均化するこのアプローチは、 平均減衰と呼ばれるテクニックで、不動点探索の収束を助けることがよくあります。

//recursive process
function cont_frac(n, d, k) {
    function fraction(i) {
        return i > k
               ? 0
               : n(i) / (d(i) + fraction(i + 1));
    }
    return fraction(1);
}

//iterative process
function cont_frac(n, d, k) {
    function fraction(i, current) {
        return i === 0
               ? current
               : fraction(i - 1, n(i) / (d(i) + current));
    }
    return fraction(k, 0);
}
