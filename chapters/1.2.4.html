1.2.4  
Exponentiation
べき乗

Consider the problem of computing the exponential of a given number. We would like a function that takes as arguments a base $b$ and a positive integer exponent $n$ and computes $b^n$. One way to do this is via the recursive definition
与えられた数のべき乗を計算する問題を考えましょう。底 $b$ と正の整数の指数 $n$ を引数として取り、$b^n$ を計算する関数が欲しいとします。1つの方法は、再帰的な定義を使うことです。
\[ \begin{array}{lll} b^{n} &=& b\cdot b^{n-1}\\ b^{0} &=& 1 \end{array} \]
which translates readily into the function
これは容易に次の関数に変換できます。 
function expt(b, n) {
    return n === 0
           ? 1
           : b * expt(b, n - 1);
}
This is a linear recursive process, which requires $\Theta(n)$ steps and $\Theta(n)$ space. Just as with factorial, we can readily formulate an equivalent linear iteration:
これは線形再帰的プロセスで、$\Theta(n)$ のステップと $\Theta(n)$ の空間を必要とします。階乗と同様に、等価な線形反復を容易に定式化できます。 
function expt(b, n) {
    return expt_iter(b, n, 1);
}
function expt_iter(b, counter, product) {
    return counter === 0
           ? product
           : expt_iter(b, counter - 1, b * product);
}
This version requires $\Theta(n)$ steps and $\Theta(1)$ space.
このバージョンは $\Theta(n)$ のステップと $\Theta(1)$ の空間を必要とします。

We can compute exponentials in fewer steps by using successive squaring. For instance, rather than computing $b^8$ as
逐次二乗法を使えば、より少ないステップでべき乗を計算できます。たとえば、$b^8$ を次のように計算する代わりに
\[ \begin{array}{l} b\cdot(b\cdot(b\cdot(b\cdot(b\cdot(b\cdot(b\cdot b)))))) \end{array} \]
we can compute it using three multiplications:
3 回の掛け算で計算できます。
\[ \begin{array}{lll} b^{2} &= & b\cdot b\\ b^{4} &= & b^{2}\cdot b^{2}\\ b^{8} &= & b^{4}\cdot b^{4} \end{array} \]

This method works fine for exponents that are powers of 2. We can also take advantage of successive squaring in computing exponentials in general if we use the rule
この方法は指数が 2 のべき乗の場合にうまく機能します。次のルールを使えば、一般のべき乗の計算でも逐次二乗法を活用できます。
\[ \begin{array}{llll} b^{n} &=& (b^{n/2})^{2} &\qquad\,\mbox{if}\ n\ \mbox{is even}\\ b^{n} &=& b\cdot b^{n-1} &\qquad\mbox{if}\ n\ \mbox{is odd} \end{array} \]
We can express this method as a function:
この方法は次の関数として表現できます。 
function fast_expt(b, n) {
    return n === 0
           ? 1
           : is_even(n)
           ? square(fast_expt(b, n / 2))
           : b * fast_expt(b, n - 1);
}
where the predicate to test whether an integer is even is defined in terms of the operator %, which computes the remainder after integer division, by
ここで、整数が偶数かどうかを判定する述語は、整数除算の余りを計算する演算子 % を使って次のように定義されます。 
function is_even(n) {
    return n % 2 === 0;
}
The process evolved by fast_expt grows logarithmically with $n$ in both space and number of steps. To see this, observe that computing $b^{2n}$ using fast_expt requires only one more multiplication than computing $b^n$. The size of the exponent we can compute therefore doubles (approximately) with every new multiplication we are allowed. Thus, the number of multiplications required for an exponent of $n$ grows about as fast as the logarithm of $n$ to the base 2. The process has $\Theta(\log n)$ growth.
fast_expt が発展させるプロセスは、 空間とステップ数の両方で $n$ に対して対数的に増加します。これを確認するには、fast_expt を使って $b^{2n}$ を計算するのに、$b^n$ の計算よりも掛け算が 1 回多いだけであることに注目します。したがって、新しい掛け算が 1 回許されるごとに、計算できる指数のサイズは（おおよそ）倍になります。つまり、指数 $n$ に必要な掛け算の回数は、$n$ の底 2 の対数とほぼ同じ速さで増加します。このプロセスは $\Theta(\log n)$ の増加を持ちます。
[1]

The difference between $\Theta(\log n)$ growth and $\Theta(n)$ growth becomes striking as $n$ becomes large. For example, fast_expt for $n=1000$ requires only 14 multiplications.
$\Theta(\log n)$ の増加と $\Theta(n)$ の増加の違いは、$n$ が大きくなると顕著になります。たとえば、fast_expt は $n=1000$ に対してわずか 14 回の掛け算しか必要としません。
[2]
It is also possible to use the idea of successive squaring to devise an iterative algorithm that computes exponentials with a logarithmic number of steps (see exercise 1.16), although, as is often the case with iterative algorithms, this is not written down so straightforwardly as the recursive algorithm.
逐次二乗法のアイデアを使って、対数的なステップ数でべき乗を計算する反復的アルゴリズムを考案することもできます（exercise 1.16を参照）。ただし、反復的アルゴリズムではよくあることですが、再帰的アルゴリズムほど直截的には書けません。
[3]

Exercise 1.16
Design a function that evolves an iterative exponentiation process that uses successive squaring and uses a logarithmic number of steps, as does fast_expt. (Hint: Using the observation that $(b^{n/2})^2 =(b^2)^{n/2}$, keep, along with the exponent $n$ and the base $b$, an additional state variable $a$, and define the state transformation in such a way that the product $a b^n$ is unchanged from state to state. At the beginning of the process $a$ is taken to be 1, and the answer is given by the value of $a$ at the end of the process. In general, the technique of defining an invariant quantity that remains unchanged from state to state is a powerful way to think about the design of iterative algorithms.)
fast_expt と同様に逐次二乗法を使い、対数的なステップ数の反復的べき乗プロセスを発展させる関数を設計してください。（ヒント：$(b^{n/2})^2 =(b^2)^{n/2}$ という観察を利用して、指数 $n$ と底 $b$ に加えて追加の状態変数 $a$ を保持し、積 $a b^n$ が状態から状態へ変わらないように状態変換を定義します。プロセスの最初に $a$ を 1 とし、答えはプロセスの終わりの $a$ の値で与えられます。一般に、状態から状態へ変わらない 不変量を定義する技法は、 反復的アルゴリズムの設計を考える強力な方法です。） 
function fast_expt_iter(a, b, n){
    return n === 0
           ? a
           : is_even(n)
           ? fast_expt_iter(a, b * b, n / 2)
           : fast_expt_iter(a * b, b, n - 1);
}
function fast_expt(b, n){
    return fast_expt_iter(1, b, n);
}
Exercise 1.17
The exponentiation algorithms in this section are based on performing exponentiation by means of repeated multiplication. In a similar way, one can perform integer multiplication by means of repeated addition. The following multiplication function (in which it is assumed that our language can only add, not multiply) is analogous to the expt function:
このセクションのべき乗アルゴリズムは、掛け算の繰り返しによるべき乗に基づいています。同様に、整数の掛け算を足し算の繰り返しで行うことができます。次の掛け算関数（言語が足し算しかできず掛け算はできないと仮定）は、expt 関数と類似しています。 
function times(a, b) {
    return b === 0
           ? 0
           : a + times(a, b - 1);
}
This algorithm takes a number of steps that is linear in b. Now suppose we include, together with addition, the functions double, which doubles an integer, and halve, which divides an (even) integer by 2. Using these, design a multiplication function analogous to fast_expt that uses a logarithmic number of steps.
このアルゴリズムは b に対して線形のステップ数を必要とします。ここで、足し算に加えて、整数を倍にする double と（偶数の）整数を 2 で割る halve という関数が使えるとしましょう。これらを使って、fast_expt と類似の、対数的なステップ数の掛け算関数を設計してください。 
function double(x) {
    return x + x;
}

function halve(x) {
    return x / 2;
}

function fast_times(a, b) { 
    return b === 1
           ? a
           : a === 0 || b === 0
           ? 0
           : is_even(b)
           ? double(fast_times(a, halve(b)))
           : a + fast_times(a, b - 1);
}

Using the results of exercises 1.16 and 1.17, devise a function that generates an iterative process for multiplying two integers in terms of adding, doubling, and halving and uses a logarithmic number of steps.
exercises 1.16 と 1.17 の結果を使って、足し算、倍化、半減の操作で 2 つの整数を掛け算する反復的プロセスを生成し、対数的なステップ数で動作する関数を考案してください。
[4] 
function double(x) {

}

function half(x) {

function fast_times_iter(total, a, b) {

function times(a, b) {
  return fast_times_iter(0, a, b);
}
Exercise 1.19
There is a clever algorithm for computing the Fibonacci numbers in a logarithmic number of steps. Recall the transformation of the state variables $a$ and $b$ in the fib_iter process of section 1.2.2: $a\leftarrow a+b$ and $b\leftarrow a$. Call this transformation $T$, and observe that applying $T$ over and over again $n$ times, starting with 1 and 0, produces the pair $\textrm{Fib}(n+1)$ and $\textrm{Fib}(n)$. In other words, the Fibonacci numbers are produced by applying $T^n$, the $n$th power of the transformation $T$, starting with the pair $(1,0)$. Now consider $T$ to be the special case of $p=0$ and $q=1$ in a family of transformations $T_{pq}$, where $T_{pq}$ transforms the pair $(a,b)$ according to $a\leftarrow bq+aq+ap$ and $b\leftarrow bp+aq$. Show that if we apply such a transformation $T_{pq}$ twice, the effect is the same as using a single transformation $T_{p'q'}$ of the same form, and compute $p'$ and $q'$ in terms of $p$ and $q$. This gives us an explicit way to square these transformations, and thus we can compute $T^n$ using successive squaring, as in the fast_expt function. Put this all together to complete the following function, which runs in a logarithmic number of steps:
フィボナッチ数を 対数的なステップ数で計算する巧妙なアルゴリズムがあります。1.2.2節の fib_iter プロセスにおける状態変数 $a$ と $b$ の変換を思い出してください。$a\leftarrow a+b$ かつ $b\leftarrow a$ です。この変換を $T$ と呼び、1 と 0 から始めて $T$ を $n$ 回繰り返し適用すると、ペア $\textrm{Fib}(n+1)$ と $\textrm{Fib}(n)$ が得られることに注目してください。つまり、フィボナッチ数はペア $(1,0)$ から始めて変換 $T$ の $n$ 乗 $T^n$ を適用することで生成されます。ここで $T$ を、変換の族 $T_{pq}$ における $p=0$、$q=1$ の特殊な場合と考えます。$T_{pq}$ はペア $(a,b)$ を $a\leftarrow bq+aq+ap$、$b\leftarrow bp+aq$ に従って変換します。変換 $T_{pq}$ を 2 回適用した効果が、同じ形の単一の変換 $T_{p'q'}$ を使うのと同じであることを示し、$p'$ と $q'$ を $p$ と $q$ で表してください。これにより変換を二乗する明示的な方法が得られ、fast_expt 関数と同様に逐次二乗法で $T^n$ を計算できます。これらをまとめて、対数的なステップ数で実行する次の関数を完成させてください。
[5] function fib(n) { return fib_iter(1, 0, 0, 1, n); } function fib_iter(a, b, p, q, count) { return count === 0 ? b : is_even(count) ? fib_iter(a, b, $\langle{}$??$\rangle$, // compute p' $\langle{}$??$\rangle$, // compute q' count / 2) : fib_iter(b * q + a * q + a * p, b * p + a * q, p, q, count - 1); } 
function fib(n) {
    return fib_iter(1, 0, 0, 1, n);
}

function fib_iter(a, b, p, q, count) {
    return count === 0
           ? b
           : is_even(count)
           ? fib_iter(a,
                      b,
                      p * p + q * q,
                      2 * p * q + q * q,
                      count / 2)
           : fib_iter(b * q + a * q + a * p,
                      b * p + a * q,
                      p,
                      q,
                      count - 1);
}
[1]
More precisely, the number of multiplications required is equal to 1 less than the log base 2 of $n$, plus the number of ones in the binary representation of $n$. This total is always less than twice the log base 2 of $n$. The arbitrary constants $k_1$ and $k_2$ in the definition of order notation imply that, for a logarithmic process, the base to which logarithms are taken does not matter, so all such processes are described as $\Theta(\log n)$.
より正確には、必要な掛け算の回数は、$n$ の底 2 の対数より 1 少ない値に、$n$ の2進表現における 1 の個数を加えたものに等しくなります。この合計は常に $n$ の底 2 の対数の 2 倍未満です。オーダー記法の定義における任意の定数 $k_1$ と $k_2$ は、対数的プロセスでは対数の底は問題にならないことを意味するので、そのようなプロセスはすべて $\Theta(\log n)$ と記述されます。
